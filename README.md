## 🛠 Our API Ecosystem

We currently maintain specialized APIs to power your financial applications:

### 1. 📈 Go Finance
Real-time market data middleware that parses global stock, crypto, and currency information directly from Google Finance.
* **Best for:** Real-time dashboards, portfolio tracking.
* [View Documentation](apis/go-finance.md)

### 2. 💹 Yahoo Finance Plus
Deep analytics and real-time pricing for 2,000+ digital assets and global equities.
* **Best for:** Crypto exchanges, institutional-grade trading bots.
* [View Documentation](apis/yahoo-finance.md)

### 3. 📰 CNBC Market & News
Dedicated API for market sentiment and high-frequency updates on global financial news.
* **Best for:** Sentiment analysis, news-driven trading signals.
* [View Documentation](apis/cnbc-data.md)

### 4. 📊 Mboum Finance Middleware
Comprehensive historical data and trend analysis for major global indexes (S&P 500, JCI, FTSE).
* **Best for:** Technical analysis, historical backtesting.
* [View Documentation](apis/mboum-finance.md)
